1. Checklist materi

2. Dasar jaringan komputer

  • LAN: jaringan di area kecil, misalnya laboratorium sekolah.
  • WAN: jaringan dengan cakupan geografis luas.
  • Switch: menghubungkan perangkat dalam jaringan lokal.
  • Router: menghubungkan jaringan yang berbeda.
  • Client-server: client meminta layanan atau data dari server.

Latihan

Gambarkan komputer client terhubung ke switch, lalu switch terhubung ke server. Jika ada jaringan lain, router dapat menghubungkan kedua jaringan.

3. IP Address dan pengujian koneksi

PerangkatContoh konfigurasi
Server192.168.10.10
Client192.168.10.11
Subnet mask255.255.255.0
Gateway contoh192.168.10.1

Windows

  1. Buka Command Prompt (CMD).
  2. Ketik ipconfig, lalu tekan Enter.
  3. Periksa IPv4 Address, Subnet Mask, dan Default Gateway.
  4. Uji koneksi ke server dengan perintah di bawah.
ping 192.168.10.10

Pembahasan: Reply from... berarti alamat tujuan memberi balasan. Jika gagal, periksa kabel, IP, subnet, firewall, dan kondisi perangkat. Ping gagal tidak selalu berarti seluruh jaringan terputus.

4. Kabel UTP dan crimping

Urutan warna T568B dari pin 1 sampai 8:

  1. Putih-oranye
  2. Oranye
  3. Putih-hijau
  4. Biru
  5. Putih-biru
  6. Hijau
  7. Putih-cokelat
  8. Cokelat

Langkah praktik

  1. Kupas kulit luar kabel secukupnya.
  2. Pisahkan dan luruskan delapan kabel kecil.
  3. Susun sesuai urutan T568B.
  4. Masukkan kabel ke konektor RJ45 sampai ujungnya rata.
  5. Jepit menggunakan tang crimping.
  6. Uji dengan LAN cable tester.

Pembahasan: Kabel straight umumnya memakai susunan yang sama di kedua ujung. Pastikan semua jalur terdeteksi pada tester. Gunakan alat sesuai arahan guru.

5. Konfigurasi router

Materi yang perlu dipahami: alamat IP interface, DHCP, gateway, dan NAT dasar.

  1. Hubungkan komputer ke router atau simulator.
  2. Buka menu konfigurasi router.
  3. Atur IP interface sesuai rancangan jaringan.
  4. Aktifkan DHCP jika dibutuhkan.
  5. Simpan konfigurasi.
  6. Periksa IP client dan uji koneksi dengan ping.

Pembahasan: DHCP membagikan konfigurasi IP otomatis. Gateway menjadi jalur menuju jaringan lain. Menu dan perintah berbeda sesuai jenis router.

Pembahasan: Login menggunakan akun dari guru, buka terminal, lalu jalankan perintah satu per satu. Ganti alamat contoh dengan IP yang benar di jaringan praktik. Tidak semua perintah memerlukan hak administrator.

7. Layanan server

SSH server

Untuk mengakses server dari jarak jauh dengan koneksi aman.

systemctl status ssh
ssh namauser@192.168.10.10

Perintah SSH kedua digunakan dari client jika layanan dan akun sudah dikonfigurasi.

Web server

Menampilkan website kepada client. Jika Apache terpasang, periksa:

systemctl status apache2

Jika server berjalan, coba buka alamat IP server dari browser client.

DNS server

Menerjemahkan nama domain menjadi alamat IP. Jika tersedia, uji dengan:

nslookup namadomain

File server

Menyediakan folder atau file bersama melalui jaringan. Pelajari folder bersama, akun pengguna, dan hak akses; salah satu layanan yang sering digunakan adalah Samba.

Catatan keamanan: Debian 10 sudah tua. Lakukan latihan di mesin virtual atau komputer lab yang diizinkan guru, bukan membuka server lama langsung ke internet.

8. Troubleshooting jaringan

  1. Periksa kabel LAN dan lampu indikator.
  2. Periksa alamat IP dengan ipconfig (Windows) atau ip addr (Linux).
  3. Pastikan IP dan subnet sesuai.
  4. Ping alamat server.
  5. Jika ping berhasil tetapi aplikasi gagal, periksa status layanan dan firewall.

Pembahasan: Mulai dari pemeriksaan paling sederhana. Jangan langsung menginstal ulang sistem atau menghapus konfigurasi.

9. Cisco Packet Tracer: jaringan sederhana

  1. Buka Cisco Packet Tracer.
  2. Tambahkan dua PC dan satu switch.
  3. Hubungkan PC ke switch menggunakan kabel yang sesuai.
  4. Atur PC pertama: IP 192.168.10.10, mask 255.255.255.0.
  5. Atur PC kedua: IP 192.168.10.11, mask 255.255.255.0.
  6. Buka Command Prompt di PC pertama dan jalankan ping 192.168.10.11.

Pembahasan: Kedua PC berada di subnet yang sama. Jika koneksi dan konfigurasi benar, ping seharusnya berhasil setelah perangkat siap.

10. Latihan soal cepat

  1. Apa fungsi IP Address?
    Jawaban: alamat logis perangkat agar dapat berkomunikasi di jaringan IP.
  2. Apa perintah Linux untuk melihat alamat IP?
    Jawaban: ip addr.
  3. Apa fungsi DNS?
    Jawaban: menerjemahkan nama domain menjadi alamat IP.
  4. Apa fungsi switch?
    Jawaban: menghubungkan perangkat dalam jaringan lokal.
  5. Apa yang diperiksa saat ping gagal?
    Jawaban: kabel, konfigurasi IP dan subnet, firewall, serta kondisi perangkat tujuan.
  6. Apa fungsi DHCP?
    Jawaban: membagikan konfigurasi IP secara otomatis kepada client.
  7. Apa fungsi SSH?
    Jawaban: mengakses perangkat/server dari jarak jauh secara aman.
